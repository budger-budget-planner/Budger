# Coherent working copies

These files are derived working copies of the immutable assets in the parent
directory. The originals remain unchanged.

- The square face variants use `base_no_eyes.png` as their canonical face.
- The one-eye and two-eye variants add the supplied eye artwork at matching
  scale and positions, so the middle off-white stripe does not change shape.
- `base_no_right_eye_aligned.png` is the production-sized wink base. It keeps
  the full-face reference intact and uses the aligned no-right-eye artwork
  only inside the right-eye repair area.
